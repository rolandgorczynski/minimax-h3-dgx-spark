# BITZI – Trick or Treat 2.0

Episode 04, released in the Halloween story sequence. The screenplay is in `story.md`; six cast-locked keyframes are in `examples/input/bitzi-trick-or-treat-2/`.

Render on the local MiniMax H3 ComfyUI service:

```sh
python3 scripts/run_bitzi_trick_or_treat_2.py
```

The six scenes run sequentially using the shared `CAST_LOCK`. The setting is the company's outdoor doorstep during trick-or-treating, with a paper costume scorecard; there is no face recognition or party-hall reprise. Assembly adds German subtitles, leveled audio, the site credit and a two-second end card.
