# Bitzi: The Ghost in the Server

The first Halloween story, scheduled for 30 October. Spoken dialogue is English; subtitles are German. Six keyframes preserve Bitzi's canonical design. MiniMax H3 generates the six video and audio segments locally in ComfyUI. FFmpeg adds the German captions, a safe normalized mix, the signature, and an ending card after the full generated clips.

Run with:

```bash
python3 scripts/run_bitzi_ghost_server.py
```

Output: `/home/jee/docker/minimax-h3-data/output/x-generator/bitzi-ghost-server/bitzi_the_ghost_in_the_server_63s.mp4`
