# Bitzi admin photo proof

A 10.125-second vertical identity and motion test rendered with the local MiniMax H3 ComfyUI workflow.

- `bitzi-admin-photo-proof.mp4`: final video with audio muxed; audio reduced by 6 dB to leave headroom.
- `../../input/bitzi-admin-photo-proof/scene1.png`: generated keyframe using the user-provided portrait and the canonical Bitzi avatar.
- `../../api/bitzi_admin_photo_proof.json`: exact ComfyUI API workflow snapshot.

The original portrait is intentionally not included in this repository; the generated keyframe is the retained project asset.
