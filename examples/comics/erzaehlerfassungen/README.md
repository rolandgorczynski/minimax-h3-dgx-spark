## Qualität und Herkunft

Die Texte werden von Codex redaktionell auf Grundlage vorhandener Handlungen, Figuren und freigegebener Sinnanalysen bearbeitet. Kein lokales oder separates Modell schreibt Ersatztexte. Technische Prüfungen kontrollieren Umfang, Sprecherzuordnung, Kontinuitätsdaten, die getrennten Textarten und die Beschriftung. Geprüft wird die gespeicherte Kachelgröße beziehungsweise 768 × 672 Pixel als Referenz; die spätere Seitenvorlage wird beim Generieren zusätzlich berücksichtigt.
