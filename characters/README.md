# Figurenakten

Jede wiederkehrende oder neu eingeführte Figur bekommt vor ihrem ersten Einsatz einen eigenen Ordner und darin eine `personality.md`. Diese Datei ist die verbindliche Figurenakte: Rolle, Persönlichkeit, Verhalten, Stimme und bekannte visuelle Referenz.

Eine neue Figur darf erst in ein Skript oder einen Videoprompt, wenn ihre Akte angelegt ist. Sind Aussehen oder Stimme noch nicht durch eine freigegebene Referenz festgelegt, muss das in der Akte ausdrücklich als offen stehen. Nichts als kanonisch ausgeben, was nur geraten wurde.

Für Bitzi-Folgen gelten außerdem die gemeinsamen Vorgaben in [`bitzi/prompts/bitzi-video.md`](bitzi/prompts/bitzi-video.md). Die vorhandenen Figurenakten:
